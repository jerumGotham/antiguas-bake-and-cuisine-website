## Shared Patterns

### Imports, aliases, and strict types
**Sources:** `.planning/codebase/CONVENTIONS.md:39-50`; `src/lib/utils.ts:1-6`

```tsx
import { cn } from "@/lib/utils"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

Use `@/` for cross-directory source imports, `import type` for type-only imports, precise props/data contracts, and no `any`. Keep special App Router files default exported; use named exports for reusable components/content.

### Semantic tokens and tactile accessibility
**Sources:** `src/app/globals.css:7-49,120-130`; `src/components/ui/button.tsx:7-20`

Use semantic `background`, `foreground`, `card`, `primary`, `border`, and `ring` utilities backed by Antigua palette variables. Preserve visible keyboard focus and 1px pressed feedback; add a global reduced-motion override. Caramel is the filled CTA/focus/indicator accent, never small text on cream or beige.

### Server shell / client leaf boundary
**Sources:** `src/app/layout.tsx:25-32`; Next 16 guide `node_modules/next/dist/docs/01-app/01-getting-started/05-server-and-client-components.md:11-31,174-205`

Layouts/pages/public shell primitives are Server Components by default. Only `mobile-menu.tsx` receives `"use client"`; its direct imports are client-bundled, so keep the boundary narrow.

### Internal versus external navigation
**Sources:** `src/app/page.tsx:42-64`; Next layouts guide `node_modules/next/dist/docs/01-app/01-getting-started/03-layouts-and-pages.md:15-20,41-89`

Use `next/link` for the sole internal Home destination. For the configured Facebook Page, use a normal anchor with `target="_blank" rel="noopener noreferrer"`. Centralize the href/label/warning in `business.ts`, then render it only through `OrderCta`.

### No application error/loading pattern
**Source:** `.planning/codebase/CONVENTIONS.md:51-64`

Phase 1 has no fetch, form, route handler, or recoverable external handoff state. Do not add try/catch, fake success/error messages, ad-hoc `console` logging, or silent factual defaults. Truthful missing expected content renders the locked placeholders; optional fields without a slot are omitted.
